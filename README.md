# 怎麼拌！？ What is the mix? — 吃法人格測驗網站

純 HTML/CSS/JS，不需要建置工具。

## 檔案

| 路徑 | 內容 |
|---|---|
| `index.html` | 網站入口 |
| `css/style.css` | 版面與像素風樣式 |
| `js/data.js` | **題目、配分、人格文字、劇情台詞**（改內容只要改這裡） |
| `js/app.js` | 流程、計分、同分規則、結果頁、存圖 |
| `js/stats.js` | 即時統計（送出作答、讀取統計） |
| `assets/` | 圖片與音樂（`bgm.mp3` 之後放這裡） |
| `apps-script/Code.gs` | 即時統計後台，貼到 Google Apps Script |

題目與配分依據：`我方產出/《怎麼拌！？》最終題目表_20261020.xlsx`。

## 本機預覽

直接用瀏覽器開 `index.html` 即可。統計後台未接上時，結果頁顯示「示範數據」。

## 待補素材

- 各場景像素風背景（目前只有封面、冰淇淋店；其他以色塊暫代）→ 放進 `assets/`，在 `css/style.css` 的 `.bg-xxx` 換成圖片
- 角色像素圖（對話框目前用 emoji 暫代）
- 五種人格的 IP 角色圖 → `js/data.js` 各人格的 `character`
- 刻板印象文字 → `js/data.js` 各人格的 `stereotype`
- 背景音樂 → `assets/bgm.mp3`

## 接上即時統計（用專案的 Google 帳號）

1. 用專案帳號建立一份 Google 試算表，例如命名為「怎麼拌 作答紀錄」。
2. 試算表選單 **擴充功能 → Apps Script**，把 `apps-script/Code.gs` 的內容整份貼上並儲存。
3. 右上 **部署 → 新增部署作業** → 類型選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 授權後複製「網頁應用程式網址」，貼到 `js/stats.js` 的 `STATS_ENDPOINT = ""` 引號中。
5. 玩一次測驗，試算表會自動新增 `responses` 分頁和一列資料。

之後修改 `Code.gs` 要重新部署時，選 **管理部署作業 → 編輯 → 新版本**，網址才不會變。

## 管理後台（收件開關、數據總覽、刪除資料）

管理後台跟統計後台是同一份 `Code.gs`，但用**另一個「只有自己能開」的部署**：

1. Apps Script **部署 → 新增部署作業 → 網頁應用程式**
   - 說明：`管理後台`
   - 執行身分：**我**
   - 具有存取權的使用者：**只有我自己**
2. 部署後複製網址，在後面加上 `?page=admin`，例如 `https://script.google.com/macros/s/xxxx/exec?page=admin`
3. 用專案帳號登入後開啟，可加到手機主畫面

功能：收件開關、總人數／今天／最後一筆、人格分布、最近 5 筆、刪除某一天或某天以前的資料（刪除前自動備份到「備份」分頁，所有操作記在「操作紀錄」分頁）。

之後更新 `Code.gs` 時，**兩個部署都要**用「管理部署作業 → 編輯 → 新版本」更新。

## 暫停收件

- **試算表**：「設定」分頁 B1 的勾選框。打勾＝收件中，取消打勾＝暫停。暫停時網站和統計照常顯示，只是不收新的作答。（第一次有人送出作答時自動建立此分頁。）
- **管理密語**（給開發者遠端切換）：在 Apps Script **專案設定 → 指令碼屬性** 新增 `ADMIN_KEY`，然後用 `我方產出/admin/mix_admin.py status|pause|resume`。密語檔 `admin-key.txt` 不在網站資料夾內，不要上傳或外流；外流時在指令碼屬性換一組新的即可。

## 上線（GitHub Pages，用專案的 GitHub 帳號）

1. 建立公開的 repository，上傳本資料夾全部檔案（`apps-script/` 可留可不留）。
2. **Settings → Pages → Branch 選 main / root → Save**。
3. 約一分鐘後得到網址 `https://<帳號>.github.io/<repo>/`，用它產生 QR code。

更新檔案後網址不變，QR code 不用重印。

**每次更新 css/js 後**，把 `index.html` 裡的 `?v=20261110g` 改成新的日期，觀眾手機才不會拿到快取的舊檔（舊程式配新資料會出錯）。

## 同分規則

1. 最高分同分時，Q13（最後直覺題）選的人格優先。
2. 仍同分，從 Q12 往前逐題看所選選項給哪個同分人格較多分。
